Feature Template

This page is the structural template every feature follows. When a real feature is played, its index page documents each run and links every functional implementation for preview.

A feature directory contains an index page, an optional supporting-files/ directory of shared inputs, and one subdirectory per participating model. Each model subdirectory holds a copy of the prompt it received (prompt.md) alongside the model's preserved output.
