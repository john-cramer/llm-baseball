Game Notes
  • Claude Fable 5 — the series outlier: the only run not driven through OpenCode, built with Claude Code on Anthropic usage credits. About 25 minutes from API exploration to a single self-contained page, with a Haiku subagent assisting for all of $0.0006.
  • GPT-5.6 Sol — the most expensive run and the most thorough tester. Most of its session went to verification: headless-browser sweeps of all 30 clubs, filesystem loading, mobile emulation, and race-condition fixes across a three-file build.
  • Kimi K3 — a single-file build wrapped up for $1.48 and verified with screenshots, with special attention to per-player stat selection: stolen bases for speedsters, saves and holds for relievers.
  • Gemini 3.1 Pro — the quickest and cheapest run: roughly twelve minutes from API exploration to completion at 3% of its context, split cleanly across HTML, CSS, and JavaScript files.
  • GLM-5.2 — the Fireworks.AI run: a steady multi-file build with late polish on pitcher role labeling, its full session transcript preserved alongside the source.
  • Qwen3.7 Max — the OpenCode Go run: a single index.html whose log records an honest debugging pass, fixing a featured-player ID mapping and a photo error handler before completion.
